# Afrikaans glossary — Crop Compliance

The key terms used across the whole app. Every screen uses these, so please
check them before the rest is translated. Mark anything you'd change.

Standard names stay as they are in both languages: **SIZA/WIETA, GlobalG.A.P.,
IPW, Fairtrade, UIF, PAYE, Crop Compliance, Farmable**.

## Not translated

- **Names people typed in** (farm names, employee names, comments, rejection
  reasons) stay exactly as entered.
- **Bank CSV files** keep the bank's required column names.
- **Numbers and money** keep the current format (R 1 234,56 style is not
  introduced) so amounts look the same in both languages.
